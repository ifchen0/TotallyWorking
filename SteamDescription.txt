A boss key that covers the game with a see-through black screen of scrolling code, so from a distance it looks like you are working. The game keeps running underneath and stays fully playable. Game windows such as the architect menu are covered too (can be switched off), and clicks still reach them.

[h2]Usage[/h2]
Press [b]F9[/b] to switch the overlay between light and heavy, and [b]Shift + F9[/b] to turn it off. The key can be changed under Options, Keyboard, and the overlay stays on or off across restarts. Hold [b]Ctrl[/b] and turn the mouse wheel to make the current level darker or lighter. The code fades along with the black screen, so the light level is easier to play on.

While the overlay is on, the game window also takes Notepad's icon and a title of your choice ("build.log - Notepad" by default) in the title bar, Alt+Tab and the taskbar. Windows only; a taskbar pin keeps the RimWorld icon.

Scroll the mouse wheel up to read back through earlier lines. The game still zooms as usual, and the view returns to the newest lines after 5 seconds.

[h2]Where the code comes from[/h2]
The code is put together while you play from the game and your loaded mods: class outlines built from their names, mixed with snippets of their XML files. It comes out in bursts with random pauses, like a build console (the pauses can be switched off). It also stops while the game is paused, so the latest game events stay on screen. Nothing from the game is copied into this mod.

[h2]Game events[/h2][list]
[*]New letters show up as [i]// TODO[/i] comments and messages as [i]// NOTE[/i] comments, in the game's colours.
[*]Errors and warnings from the debug log show up as red and yellow compiler errors.
[*]Live colony status: alerts, colonist state changes (downed, mental breaks, drafting, injuries), optional job changes and an hourly colony summary. Events that happen together are merged into one line.
[*][b]Log only[/b] (off by default) drops the fake code and shows just these events, as a live colony log.
[/list]

[h2]Notes[/h2][list]
[*]Darkness of each level, scroll speed, text size and which events to show are in the mod settings.
[*]Safe to add to or remove from an existing save.
[/list]
